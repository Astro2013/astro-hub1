# Astro Galaxy — updated now.gg portal

These files replace the existing root files in your `Astro2013/astro-hub` repository.

## Files
- `index.html` — hub layout and now.gg portal card
- `style.css` — purple space theme and responsive styling
- `app.js` — built-in mini-games and now.gg launch controls

## Install on GitHub
1. Open your repository and choose **Add file → Upload files**.
2. Upload `index.html`, `style.css`, and `app.js` from this folder.
3. Choose to replace the existing files when GitHub asks, then commit to `main`.
4. Refresh your GitHub Pages website. A hard refresh (`Ctrl+Shift+R`) can help.

## About now.gg
The Cloud Player tries to load `https://now.gg/` inside Astro's game area and also provides a separate-tab link. now.gg may block iframe embedding; if so, use **Open now.gg in new tab**. This is a launcher, not a proxy, and it does not create a cloud gaming session. Games, access, sign-in, and any limits remain controlled by now.gg.
